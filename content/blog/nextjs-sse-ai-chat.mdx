## 项目概述

本文介绍如何构建浏览器端侧离线AI聊天应用，模型直接在浏览器运行，不需要后端大模型接口、不需要API Key。核心思路是借助 **Transformers.js**，利用 WebGPU 做硬件加速，在前端完成大模型推理，实现离线对话、打字机流式输出。

## 架构设计

### 端侧模型环境配置

配置 Transformers.js 运行环境，开启 WebGPU 加速，开启浏览器缓存，优化重复加载速度：

```typescript
import { env } from '@xenova/transformers'

// 使用 WebGPU 硬件后端
env.backend = 'webgpu'
// 开启浏览器 IndexedDB 模型缓存
env.useBrowserCache = true
// 限制纹理大小，适配低配显卡
env.maxTextureSize = 4096
// 关闭冗余日志
env.logLevel = 'error'
```

### 前端本地流式推理

在 Next.js API Route 封装本地模型流式输出，复用 SSE 协议，和云端接口保持相同调用格式：

```typescript
import { pipeline } from '@xenova/transformers'

let chatPipeline: any = null

async function initLocalModel() {
  chatPipeline = await pipeline(
    'text-generation',
    'Xenova/Qwen1.5-1.8B-Chat-GGUF'
  )
}

export async function POST(req: Request) {
  const { messages } = await req.json()

  if (!chatPipeline) {
    await initLocalModel()
  }

  const stream = await chatPipeline(messages, {
    stream: true,
    max_new_tokens: 1024,
    temperature: 0.7,
  })

  const encoder = new TextEncoder()
  const readable = new ReadableStream({
    async start(controller) {
      for await (const chunk of stream) {
        const content = chunk.output_text
        if (content) {
          controller.enqueue(
            encoder.encode(`data: ${JSON.stringify({ content })}\n\n`)
          )
        }
      }
      controller.enqueue(encoder.encode('data: [DONE]\n\n'))
      controller.close()
    },
  })

  return new Response(readable, {
    headers: { 'Content-Type': 'text/event-stream' },
  })
}
```

## 前端实现要点

### SSE 流式读取

前端消费 SSE 流，逐块接收数据更新 UI：

```typescript
async function sendChat(messages: Array<{role:string, content:string}>) {
  const res = await fetch('/api/local-chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ messages }),
  })

  const reader = res.body!.getReader()
  const decoder = new TextDecoder()
  let fullText = ''

  while (true) {
    const { done, value } = await reader.read()
    if (done) break

    const text = decoder.decode(value)
    const lines = text.split('\n\n').filter(Boolean)
    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const payload = JSON.parse(line.replace('data: ', ''))
        fullText += payload.content
        // 更新页面 state
      }
    }
  }
}
```

## 端侧模型对比

| 模型 | 优势 | 适用场景 |
|------|------|---------|
| Qwen‑1.5‑1.8B‑Chat | 体积小，中文好 | 浏览器日常对话 |
| Llama‑3‑2.8B‑Instruct | 逻辑强 | 简单推理、文案生成 |
| Mistral‑7B‑Instruct‑GGUF | 能力强，显存要求高 | PC端复杂任务 |
| Qwen2‑0.5B‑Chat | 占用极低，速度快 | 低端设备原型演示 |

## 总结

借助 Transformers.js + WebGPU，可以把量化后的大模型直接跑在浏览器。不需要后端API、不需要密钥，数据全部本地处理，隐私性好。只需要更换模型ID，就可以切换不同端侧模型，架构易于扩展，是2026前端AI非常热门的实现方案。
