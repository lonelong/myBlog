## 项目概述

传统前端项目接入AI能力，普遍存在架构改造成本高、代码侵入性强、模型适配单一、复用性差等问题。很多团队为了实现简单的文本润色、智能问答、内容摘要功能，需要搭建专属后端服务，极大提升了开发与维护成本。

本文将介绍一套<strong>零侵入、轻量化、高复用</strong>的前端AI落地方案，基于Next.js搭建，依托主流大模型通用的OpenAI兼容接口，无需重构项目架构，即可快速接入DeepSeek、GPT、Gemini、Claude等多款大模型，快速实现各类前端智能业务能力。

## 架构设计

### 统一多模型接口层

当前主流商用大模型均全面兼容OpenAI API请求规范，依托这一特性，我们可通过一套OpenAI SDK，仅切换请求地址与密钥，完成全平台模型适配，彻底告别多模型多套代码的冗余开发模式。

```typescript
import OpenAI from 'openai'

// 统一封装多模型客户端实例
// DeepSeek 高性价比通用模型
const deepseekAI = new OpenAI({
  baseURL: 'https://api.deepseek.com/v1',
  apiKey: process.env.DEEPSEEK_API_KEY,
})

// Gemini 极速响应模型
const geminiAI = new OpenAI({
  baseURL: 'https://generativelanguage.googleapis.com/v1beta/openai',
  apiKey: process.env.GEMINI_API_KEY,
})

// OpenAI 通用模型
const openaiAI = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
})
```

### 通用 SSE 流式响应封装

为贴合前端交互体验，采用Server-Sent Events流式输出方案，实现AI内容逐字展示效果，统一所有模型的接口返回格式，适配全部前端AI业务场景。

```typescript
export async function POST(req: Request) {
  const { messages, model } = await req.json()

  // 根据模型类型匹配对应客户端
  let client
  if (model.includes('deepseek')) client = deepseekAI
  else if (model.includes('gemini')) client = geminiAI
  else client = openaiAI

  // 发起流式AI推理请求
  const stream = await client.chat.completions.create({
    model,
    messages,
    stream: true,
  })

  const encoder = new TextEncoder()
  const readable = new ReadableStream({
    async start(controller) {
      for await (const chunk of stream) {
        const content = chunk.choices[0]?.delta?.content
        if (content) {
          controller.enqueue(
            encoder.encode(`data: ${JSON.stringify({ content })}\n\n`)
          )
        }
      }
      controller.enqueue(encoder.encode('data: [DONE]\n\n'))
      controller.close()
    },
  })

  return new Response(readable, {
    headers: { 'Content-Type': 'text/event-stream' },
  })
}
```

### AI富文本 Markdown 渲染

大模型返回内容默认携带Markdown语法，通过react-markdown实现标准化渲染，支持代码块、表格、换行、加粗等通用格式，优化前端展示效果。

```typescript
import ReactMarkdown from 'react-markdown'
import remarkGfm from 'remark-gfm'

// 全局通用AI内容渲染组件
<ReactMarkdown remarkPlugins={[remarkGfm]}>
  {message.content}
</ReactMarkdown>
```

## 总结

前端轻量化落地AI能力的核心逻辑，是依托<strong>统一兼容接口+通用流式架构</strong>，以最低成本实现前端项目智能化升级。该方案无需复杂后端架构支撑、代码侵入性极低、模型可自由切换，一套底层逻辑可适配全部前端AI业务场景。不仅大幅降低了前端AI开发门槛，同时具备极强的可扩展性，后续新增大模型厂商无需重构代码，仅需新增客户端实例即可快速接入，是适配绝大多数前端项目的轻量化AI最优落地方案。
